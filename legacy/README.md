# Legacy LTX prototype

This directory archives the original LTX/HTML prototype that was used as the creative
reference for NewsReel V2.

It is **not** part of the production runtime. The production entrypoints are:

- `bridge.py`
- `modal_h3.py`
- `newsreel/`
- `web/index.html`

Do not deploy or run the legacy bridge/worker for production smoke tests.
